# Mode C: Embedded Developer SDK

**Mode C** packages Avecinna's core security engines into a standalone, universal npm library: **`@avecina/sdk`** (and `@avecina/security-middleware`).

HealthTech engineering teams can embed enterprise-grade CAAC zero-trust authorization, OWASP API3 DTO masking, and isolated Merkle audit ledgers directly into their custom Node.js microservices with a single line of middleware.

---

## 1. Installation

```bash
npm install @avecina/sdk
# or
pnpm add @avecina/sdk
```

---

## 2. Express.js Integration

```typescript
import express from 'express';
import { createAvecinnaSDK } from '@avecina/sdk';

const app = express();
const sdk = createAvecinnaSDK({
  primaryDbUrl: process.env.DATABASE_URL,
  auditDbUrl: process.env.AUDIT_DATABASE_URL,
  enforceCaac: true,
  enforceDtoMasking: true,
});

// Attach Avecinna Zero-Trust Security Middleware
app.use(sdk.express({ patientIdParam: 'id' }));

// Downstream handler receives pre-authenticated & CAAC-verified context
app.get('/patients/:id', async (req, res) => {
  // req.avecina.patient is automatically loaded and pre-masked by role
  res.json(req.avecina.patient);
});

app.listen(3000);
```

---

## 3. Fastify Integration

```typescript
import Fastify from 'fastify';
import { createAvecinnaFastifyPlugin } from '@avecina/security-middleware';

const fastify = Fastify();

await fastify.register(createAvecinnaFastifyPlugin({
  primaryDbUrl: process.env.DATABASE_URL,
  auditDbUrl: process.env.AUDIT_DATABASE_URL,
  enforceCaac: true,
  enforceDtoMasking: true,
}));

fastify.get('/patients/:id', async (request, reply) => {
  return request.avecina.patient;
});

await fastify.listen({ port: 3000 });
```

## 4. Standalone Programmatic Usage

For non-HTTP microservices (e.g., GraphQL resolvers, gRPC endpoints, Kafka consumers):

```typescript
import { createAvecinnaSDK } from '@avecina/sdk';

const sdk = createAvecinnaSDK({
  primaryDbUrl: process.env.DATABASE_URL,
  auditDbUrl: process.env.AUDIT_DATABASE_URL,
});

// 1. Evaluate CAAC Directly
const decision = await sdk.caac.evaluate({
  userId: 'u-doc-cardio',
  role: 'DOCTOR',
  activeWardId: 'w-cardio',
  patientId: 'p-cardio-01',
});

if (!decision.isPermitted) {
  throw new Error(`CAAC Authorization Denied: ${decision.denialReason}`);
}

// 2. Append Audit Block Directly
const receipt = await sdk.audit.appendBlock({
  userId: 'u-doc-cardio',
  patientId: 'p-cardio-01',
  action: 'CUSTOM_AI_DIAGNOSTIC_QUERY',
  activeWard: 'w-cardio',
  payload: { inferenceId: 'inf-9812' },
});

console.log('Block Sealed with Hash:', receipt.blockHash);
```
