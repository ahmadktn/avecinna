# Nuxt 4 Clinical Frontend Architecture

The Avecinna frontend is built with **Nuxt 4** leveraging the `app/` directory structure, Vue 3 Composition API, and TailwindCSS.

---

## 1. Directory Structure

```text
frontend/
├── app/
│   ├── assets/
│   │   └── css/main.css         # Typography, Space Grotesk/Inter, color tokens
│   ├── components/
│   │   ├── AppNavbar.vue        # Global navigation bar with ward selector & profile
│   │   ├── AppSidebar.vue       # Role-specific sidebar navigation
│   │   ├── BreakGlassModal.vue  # Tier 1 / Tier 2 emergency break-glass modal
│   │   ├── CareTeamModal.vue    # Multidisciplinary care team management modal
│   │   └── VitalsModal.vue      # Nursing triage & vital signs recording modal
│   ├── composables/
│   │   ├── useApi.ts            # Fastify API client with offline retry handling
│   │   ├── useAuth.ts           # Authentication & active ward state management
│   │   └── useOfflineStorage.ts # IndexedDB + Web Crypto AES-GCM-256 client cache
│   ├── layouts/
│   │   ├── default.vue          # Authenticated layout with Navbar + Sidebar
│   │   └── auth.vue             # Minimal layout for login & session recovery
│   └── pages/                   # Role-scoped routes (doctor, nurse, clerk, pharmacy, admin)
├── public/
│   ├── sw.js                    # Web Service Worker for background sync
│   └── icons/                   # Medical SVG iconography
└── nuxt.config.ts               # Nuxt 4 configuration & Tailwind integration
```

## 2. Design System & Zero-Emoji Standard

::alert{type="info"}
**Workspace Design Rule:** Never use emojis in the clinical UI. Always use real, standardized SVG icons (Lucide / Heroicons) and Space Grotesk / Inter medical typography.
::

### Color Palette Tokens
- **Backgrounds:** `--color-slate-50` (Canvas), `#ffffff` (Card surfaces), `--color-slate-900` (Dark mode).
- **Text:** `--color-slate-900` (Headers / Primary), `--color-slate-500` (Labels / Secondary).
- **Accents:** Medical Blue (`--color-blue-600`), Emerald (`--color-emerald-600`), Amber (`--color-amber-600`), Critical Red (`--color-red-600`).
