# Quick Start Guide

This guide walks you through setting up a complete Avecinna development environment from scratch.

---

## Prerequisites

Ensure you have the following installed on your machine:
- **Node.js**: `v20.x` or higher
- **pnpm**: `v9.x` or higher (`npm i -g pnpm`)
- **PostgreSQL**: `v14+` running locally or via Docker

---

## Step 1: Clone Repository & Install Dependencies

```bash
git clone https://github.com/vitalsdeck/avecinna.git
cd avecinna

# Install backend dependencies
cd backend && pnpm install

# Install frontend dependencies
cd ../frontend && pnpm install
```

---

## Step 2: Configure Environment Variables

Create `.env` inside `backend/`:

```ini
# Primary Operational Database
DATABASE_URL=postgres://postgres:postgres@localhost:5432/avecinna_primary_db

# Physically Isolated Audit Database
AUDIT_DATABASE_URL=postgres://postgres:postgres@localhost:5432/avecinna_audit_db

# JWT & Application Security
JWT_SECRET=super-secret-development-key-32-chars-long
PORT=3001
HOST=0.0.0.0
CORS_ORIGIN=http://localhost:3000

# Mode B Upstream EMR (Optional - e.g. OpenMRS / FHIR)
UPSTREAM_EMR_URL=https://openmrs.local/ws/rest/v1
```

Create `.env` inside `frontend/`:

```ini
NUXT_PUBLIC_API_BASE=http://localhost:3001/api/v1
```

---

## Step 3: Database Migrations & Seeding

Create the two isolated PostgreSQL databases:

```sql
CREATE DATABASE avecinna_primary_db;
CREATE DATABASE avecinna_audit_db;
```

Run Drizzle schema push and automated seeding:

```bash
cd backend
pnpm db:push
pnpm db:seed
```

::alert{type="success"}
The seed script generates demo wards (`w-cardio`, `w-icu`, `w-peds`, `w-opd`), shift rosters, sample inpatient records, and pre-configured clinician accounts.

## Step 4: Run Development Servers

Open two terminal windows:

::code-group
```bash [Terminal 1: Backend API]
cd backend
pnpm dev
# Server listening at http://localhost:3001
```

```bash [Terminal 2: Nuxt 4 Frontend]
cd frontend
pnpm dev
# Nuxt 4 client listening at http://localhost:3000
```
::

Visit `http://localhost:3000` in your browser to sign in to the clinical workstation.
