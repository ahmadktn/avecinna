# Care Team Collaboration API

Endpoints enabling physicians to grant cross-ward consultation privileges to multidisciplinary specialists (e.g., Nephrology, Infectious Disease, Clinical Pharmacy).

---

## 1. List Available Multidisciplinary Staff

`GET /api/v1/care-teams/available-staff`

Returns active hospital staff available for consultation grants, categorized by role.

### Response (200 OK)
```json
[
  {
    "id": "u-doc-nephro",
    "name": "Dr. Marcus Chen",
    "email": "doctor.nephro@avecinna.org",
    "role": "DOCTOR",
    "department": "Nephrology",
    "homeWardId": "w-icu"
  }
]
```

---

## 2. Grant Care Team Consult Access

`POST /api/v1/patients/:id/care-teams`

Restricted to `DOCTOR`, `HEAD_OF_UNIT`, and `ADMIN`. Grants cross-ward CAAC authorization to the assigned clinician until `expiresAt`.

### Request Body
```json
{
  "staffId": "u-doc-nephro",
  "relationshipType": "CONSULT",
  "expiresAt": "2026-09-24T18:00:00.000Z",
  "notes": "Urgent renal consult for acute kidney injury management."
}
```

### Response (201 Created)
```json
{
  "success": true,
  "careTeamId": "ct-4019",
  "auditBlockHash": "b73a...912f"
}
```

---

## 3. Revoke Care Team Member

`DELETE /api/v1/patients/:id/care-teams/:careTeamId`

Revokes consultation access immediately and appends a `CARE_TEAM_REVOKE` block into `avecinna_audit_db`.
