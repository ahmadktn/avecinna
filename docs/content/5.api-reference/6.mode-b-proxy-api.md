# Mode B Reverse Proxy API

Endpoints enabling zero-trust protection for external FHIR and OpenMRS servers.

---

## 1. Upstream EMR Proxy Gateway

`ALL /api/v1/emr-proxy/*`

Intercepts any HTTP request (`GET`, `POST`, `PUT`, `DELETE`, `PATCH`) destined for the upstream legacy EMR configured via `UPSTREAM_EMR_URL`.

### Required Headers
- `Authorization: Bearer <jwt_token>`
- `X-Active-Ward-Id: <ward_id>` (Clinician active ward context)

### Response Headers Attached by Sidecar
- `X-Avecinna-Execution-Mode: MODE_B`
- `X-Avecinna-Audit-Logged: true`
- `X-Avecinna-Relationship-Type: PRIMARY | CONSULT | BREAK_GLASS`
- `X-Audit-Block-Hash: <sha256_hash>`
- `X-Merkle-Root: <root_hash>`

### Example cURL Execution

```bash
curl -X GET "https://avecinna-proxy.hospital.org/api/v1/emr-proxy/ws/rest/v1/patient/p-cardio-01" \
  -H "Authorization: Bearer eyJhbGciOi..." \
  -H "X-Active-Ward-Id: w-cardio"
```
