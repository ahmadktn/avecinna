# Authentication & Session API

All Avecinna API endpoints (with the exception of `/auth/login`) require a valid JWT Bearer Token passed in the `Authorization` header:

```http
Authorization: Bearer <jwt_token>
```

---

## 1. User Login

`POST /api/v1/auth/login`

Authenticates clinician credentials, verifies active shift roster status, and returns a signed JWT token containing default home ward context.

### Request Body
```json
{
  "email": "doctor.cardio@avecinna.org",
  "password": "Password123!"
}
```

### Response (200 OK)
```json
{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "user": {
    "id": "u-doc-cardio",
    "email": "doctor.cardio@avecinna.org",
    "name": "Dr. Sophia Reynolds",
    "role": "DOCTOR",
    "homeWardId": "w-cardio",
    "activeWardId": "w-cardio",
    "shiftStart": "2026-09-20T08:00:00.000Z",
    "shiftEnd": "2026-09-20T20:00:00.000Z"
  }
}
```

## 2. Dynamic Ward Context Switch

`POST /api/v1/auth/switch-ward`

Allows clinicians to switch their active working ward context. The backend enforces:
1. `homeWardId === targetWardId`, or
2. Clinician has an active scheduled shift in `ward_rosters` for today, or
3. Clinician holds an active, non-expired care team consult on a patient in `targetWardId`.

### Request Body
```json
{
  "targetWardId": "w-icu"
}
```

### Response (200 OK)
```json
{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "activeWardId": "w-icu",
  "message": "Ward context switched successfully."
}
```

### Error Response (403 Forbidden)
```json
{
  "error": "Forbidden",
  "message": "WARD_SWITCH_BLOCKED: You do not have an active shift roster or care team consultation in target ward w-icu."
}
```
