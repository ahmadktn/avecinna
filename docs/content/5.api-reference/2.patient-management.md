# Patient Management API

Endpoints for patient registration, ward census filtering, and chart retrieval.

---

## 1. List Ward Patients (Scoped Census)

`GET /api/v1/patients`

Returns all inpatients currently admitted to the clinician's `activeWardId`, plus any cross-ward patients where the clinician is an active member of the multidisciplinary care team.

### Headers
- `Authorization: Bearer <token>`
- `X-Active-Ward-Id: w-cardio` (Optional override)

### Response (200 OK)
```json
[
  {
    "id": "p-cardio-01",
    "mrn": "MRN-2026-0891",
    "fullName": "Eleanor Vance",
    "assignedBed": "Bed 4B",
    "primaryWardId": "w-cardio",
    "status": "ADMITTED",
    "patientType": "INPATIENT"
  }
]
```

---

## 2. Get Patient Clinical Chart (CAAC Protected)

`GET /api/v1/patients/:id`

Retrieves the patient's record. Evaluates `evaluateCAAC()` and serializes data via `filterPatientRecordByRole()`.

### Error Responses
- **403 Forbidden (BOLA Violation):**
  ```json
  {
    "error": "Forbidden",
    "message": "NO_WARD_OR_CARE_TEAM_RELATIONSHIP: Access denied to out-of-ward patient chart."
  }
  ```

---

## 3. Register New Patient

`POST /api/v1/patients`

Registers a new patient and assigns primary ward admission. Restricted to `CLERK`, `ADMIN`, and `HEAD_OF_UNIT`.

### Request Body
```json
{
  "mrn": "MRN-2026-9901",
  "fullName": "James Wilson",
  "dateOfBirth": "1982-07-21",
  "gender": "MALE",
  "patientType": "INPATIENT",
  "primaryWardId": "w-cardio",
  "assignedBed": "Bed 1A"
}
```
