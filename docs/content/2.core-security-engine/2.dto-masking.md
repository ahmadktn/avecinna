# Server-Side Role DTO Masking

In modern Single Page Applications (SPAs), filtering sensitive data only on the frontend via UI conditions (`v-if`) leaves the API vulnerable to **OWASP API3:2023 Excessive Data Exposure**. Any authenticated staff member can inspect the raw HTTP response payloads in their browser DevTools and view unauthorized clinical notes, psychiatric diagnoses, or confidential medical records.

Avecinna completely mitigates this vulnerability by executing **Server-Side Role DTO Masking** via [`backend/src/services/dtoMasker.ts`](file:///home/ahmadbb/Documents/avecinna/backend/src/services/dtoMasker.ts).

## 2. Administrator Clinical Privacy Restriction Rule

::alert{type="danger"}
**HIPAA Technical Safeguard (§164.312): System Administrators Must NOT View Medical ePHI.**
::

System Administrators manage infrastructure, user provisioning, ward configurations, and cryptographic Merkle verification. When an Administrator queries patient records, Avecinna returns:

```json
{
  "id": "p-cardio-01",
  "mrn": "MRN-2026-0891",
  "fullName": "Eleanor Vance",
  "assignedBed": "Bed 4B",
  "primaryWardId": "w-cardio",
  "vitals": "[REDACTED - ADMIN PRIVACY RESTRICTION]",
  "activeMedications": "[REDACTED - ADMIN PRIVACY RESTRICTION]",
  "allergies": "[REDACTED - ADMIN PRIVACY RESTRICTION]",
  "clinicalNotes": "[REDACTED - ADMIN PRIVACY RESTRICTION]",
  "adminPrivacyNotice": "System Administrators manage infrastructure and verify Merkle audit chains but are strictly prohibited from viewing patient clinical data."
}
```

## 3. Server-Side Masking Implementation

```typescript
export function filterPatientRecordByRole(patient: any, role: string, isBreakGlass: boolean = false): any {
  if (isBreakGlass || role === 'DOCTOR' || role === 'HEAD_OF_UNIT') {
    return patient; // Full clinical view
  }

  if (role === 'NURSE' || role === 'PARAMEDIC') {
    return {
      id: patient.id,
      mrn: patient.mrn,
      fullName: patient.fullName,
      assignedBed: patient.assignedBed,
      primaryWardId: patient.primaryWardId,
      vitals: patient.vitals,
      activeMedications: patient.activeMedications,
      allergies: patient.allergies,
      carePlan: patient.carePlan,
      // clinicalNotes, psychiatricHistory, and unverified lab attachments are omitted
    };
  }

  if (role === 'CLERK') {
    return {
      id: patient.id,
      mrn: patient.mrn,
      fullName: patient.fullName,
      dateOfBirth: patient.dateOfBirth,
      gender: patient.gender,
      assignedBed: patient.assignedBed,
      primaryWardId: patient.primaryWardId,
    };
  }

  if (role === 'ADMIN') {
    return {
      id: patient.id,
      mrn: patient.mrn,
      fullName: patient.fullName,
      assignedBed: patient.assignedBed,
      primaryWardId: patient.primaryWardId,
      vitals: '[REDACTED - ADMIN PRIVACY RESTRICTION]',
      activeMedications: '[REDACTED - ADMIN PRIVACY RESTRICTION]',
      allergies: '[REDACTED - ADMIN PRIVACY RESTRICTION]',
      clinicalNotes: '[REDACTED - ADMIN PRIVACY RESTRICTION]',
      adminPrivacyNotice: 'System Administrators manage infrastructure and verify Merkle audit chains but are strictly prohibited from viewing patient clinical data.',
    };
  }

  return patient;
}
```
