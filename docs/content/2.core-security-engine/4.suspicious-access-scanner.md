# Suspicious Access Scanner

The **Suspicious Access Scanner** (`backend/src/services/scannerService.ts`) runs continuous heuristic analysis over live audit blocks to detect insider threats, rogue data harvesting, and anomalous clinician behavior.

---

## 1. Real-Time Detection Rules

| Rule ID | Rule Name | Detection Criteria | Severity | Action Triggered |
| :--- | :--- | :--- | :---: | :--- |
| **RULE_01** | **Excessive Break-Glass Usage** | Clinician activates Tier 2 Break-Glass $> 3$ times in a single 8-hour shift. | `CRITICAL` | Dispatches security alert & flags clinician profile for compliance review. |
| **RULE_02** | **Rapid Ward Hopping** | Clinician switches active ward $> 4$ times across different departments within 15 minutes. | `HIGH` | Re-evaluates shift roster permissions and alerts Unit Chief. |
| **RULE_03** | **Expired Consult Access Attempt** | Clinician attempts to query a patient chart after their care team consultation has expired. | `MEDIUM` | Generates BOLA rejection block and alert log. |
| **RULE_04** | **Unscheduled Shift Access Attempt** | Off-duty clinician makes $> 5$ record queries outside their assigned shift window. | `HIGH` | Blocks session and requires supervisor re-authorization. |

---

## 2. Security Alerts Database Model

When an anomaly is flagged, a record is inserted into the `security_alerts` table in `avecinna_primary_db`:

```sql
CREATE TABLE security_alerts (
    id VARCHAR(36) PRIMARY KEY,
    severity VARCHAR(20) NOT NULL, -- 'LOW' | 'MEDIUM' | 'HIGH' | 'CRITICAL'
    rule_id VARCHAR(50) NOT NULL,
    user_id VARCHAR(36) NOT NULL REFERENCES users(id),
    patient_id VARCHAR(36) REFERENCES patients(id),
    ward_id VARCHAR(36) REFERENCES wards(id),
    description TEXT NOT NULL,
    metadata JSONB DEFAULT '{}'::jsonb,
    is_resolved BOOLEAN DEFAULT FALSE,
    resolved_by VARCHAR(36) REFERENCES users(id),
    resolved_at TIMESTAMP,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

Administrators and Compliance Officers review and resolve these incidents in the **Admin Security Dashboard** (`/admin/dashboard`).
